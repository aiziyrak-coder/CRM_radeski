# AI tahlil (4-bosqich): yoqish va ishlatish

## Nima qiladi

Har bir yozib olingan, kamida 15 soniyalik suhbat avtomatik ravishda:

1. **Matnga o'giriladi** — stereo yozuvning ikki kanali alohida (chap = operator, o'ng = bemor),
   vaqt belgilari bilan.
2. **Tahlil qilinadi** (OpenAI, structured outputs — javob faqat belgilangan JSON sxemada):
   - suhbat turi (qaysi skriptga mos);
   - 8 mezon bo'yicha baho → 0–100 ball (ballni model emas, CRM hisoblaydi: bajarilgan
     mezonlar vaznining ulushi);
   - buzilishlar — iqtibos va vaqt bilan (QA panelida o'sha joyni bir tugma bilan tinglash);
   - **qizil bayroqlar**: tashxis/davolash maslahati, bosim, asossiz va'da, shikoyat;
   - natija va sabab taklifi, qiziqish, qulay vaqt, keyingi qadam, 2–3 gaplik xulosa;
   - bemor savollari va e'tirozlari (haftalik dayjest uchun).
3. **Operatorga**: vazifa kartasida “AI xulosasi” chiqadi — **Tasdiqlash** (bir tugma) yoki
   **Tuzatish**. Operator o'zgartirgan joylar saqlanadi — promptni yaxshilash uchun eval to'plami.
4. **Rahbarga**: “Sifat nazorati” sahifasi — operatorlar va mezonlar bo'yicha ko'rsatkichlar,
   eng yomon/yaxshi qo'ng'iroqlar, qizil bayroqlar (ko'rib chiqildi deb belgilash), mezonlarni
   tahrirlash, har dushanba 08:00 da haftalik dayjest.
5. **Qo'ng'iroqdan oldin**: vazifada “Bemor haqida qisqacha” — tashriflar, oldingi suhbatlar
   xulosasi, ochiq vazifalar (6 soat keshlanadi).
6. **Tashxislar**: qoidaga tushmagan yozuvlarga AI toifa taklif qiladi (“AI taklifi” tugmasi yoki
   `python -m app.cli ai-diagnoses`); shifokor tasdiqlamaguncha bemorlarga qo'llanmaydi.

AI hech qachon o'zi vazifani yopmaydi, bemorga yozmaydi va qo'ng'iroq qilmaydi.

## Yoqish

`.env` ga:

```bash
OPENAI_API_KEY=sk-...
```

keyin:

```bash
docker compose -p radeski-crm -f docker-compose.prod.yml up -d --no-deps api worker beat
```

Kalit qo'shilgach oxirgi 7 kunlik yozuvlar ham navbat bilan tahlil qilinadi (har 30 daqiqada
50 tadan). Holatni “Sifat nazorati” sahifasining yuqorisida ko'rish mumkin.

| O'zgaruvchi | Standart | Izoh |
|---|---|---|
| `AI_STT_MODEL` | `gpt-4o-transcribe-diarize` | vaqt belgilari beradi; `whisper-1` ham beradi; boshqalari matnni bitta blok qiladi |
| `AI_LLM_MODEL` | `gpt-5.4-mini` | tahlil, xulosa, dayjest |
| `AI_REASONING_EFFORT` | `low` | reasoning bo'lmagan model uchun bo'sh qoldiring |
| `AI_MIN_TALK_SECONDS` | `15` | bundan qisqa suhbatlar tahlil qilinmaydi |
| `AI_MAX_OUTPUT_TOKENS` | `6000` | javob kesilsa oshiring |

## Modelni tanlash (4.1 — STT benchmark)

1. 30 ta turli qo'ng'iroq yozuvini (o'zbekcha, ruscha, aralash, shovqinli) oling:
   `radeski_crm_recordings` volume'idan yoki “Qo'ng'iroqlar” sahifasidan yuklab.
2. Har biri uchun qo'lda to'g'ri matn yozing: `call01.mp3` + `call01.txt` (bir papkada,
   **git'dan tashqarida** — bu shaxsiy ma'lumot).
3. Serverda:

```bash
docker compose -p radeski-crm -f docker-compose.prod.yml run --rm -v /home/radeski-crm/data/stt:/stt api \
  python -m app.cli stt-benchmark --dir /stt
```

Natija: har model uchun WER (so'z xatosi foizi), vaqt va narx. Eng yaxshisini
`AI_STT_MODEL` ga yozing. WER 25% dan yuqori bo'lsa — o'zbek tiliga ixtisoslashgan STT provayderini
adapter orqali ulash kerak bo'ladi (`backend/app/integrations/stt/`).

## Ma'lumotlar himoyasi

- OpenAI'ga **audio** (STT uchun) va **transkript** (tahlil uchun) yuboriladi. Transkriptdagi
  telefon, pasport va karta raqamlari `[raqam]` bilan almashtiriladi. Bemor ismi, raqami va
  manzili qisqa ma'lumot uchun yuborilmaydi (faqat tashxislar, tashriflar va holatlar).
- IVR boshida “suhbat yozib olinadi va sifat nazorati uchun tahlil qilinadi” ogohlantirishi bo'lishi
  shart (`telephony/sounds/welcome.wav`).
- OpenAI tashkilot sozlamalarida (platform.openai.com → Settings → Data controls) ma'lumotni
  o'qitishda ishlatmaslik va minimal saqlash muddatini tanlang.
- Yakuniy sxemani yurist tasdiqlaydi (TZ 5-bo'lim).

## Narx (taxminiy)

2 operator × kuniga ~60 suhbat × o'rtacha 3 daqiqa ≈ oyiga 4 000 daqiqa audio.
Ikki kanal alohida o'giriladi → ~8 000 daqiqa STT. Tahlil: har suhbatga ~6–8 ming token kirish
(skriptlar qismi keshlanadi) + ~1 ming token chiqish. Aniq narxni OpenAI'ning joriy narxlari
va benchmark natijasi bo'yicha hisoblang; `platform.openai.com/usage` da kunlik sarfni kuzating.
