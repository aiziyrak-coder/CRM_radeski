# AI tahlil (4-bosqich): yoqish va ishlatish

## Nima qiladi

Har bir yozib olingan, kamida 20 soniyalik suhbat avtomatik ravishda:

1. **Matnga o'giriladi** — stereo yozuvning ikki kanali alohida (chap = operator, o'ng = bemor).
   Har kanaldagi jimlik serverning o'zida (ffmpeg) kesib tashlanadi va OpenAI'ga faqat gapirilgan
   bo'laklar yuboriladi — vaqt belgilari shu bo'laklardan olinadi.
2. **Tahlil qilinadi** (OpenAI, structured outputs — javob faqat belgilangan JSON sxemada):
   - suhbat turi (qaysi skriptga mos);
   - 8 mezon bo'yicha baho → 0–100 ball (ballni model emas, CRM hisoblaydi: bajarilgan
     mezonlar vaznining ulushi);
   - buzilishlar — iqtibos va vaqt bilan (QA panelida o'sha joyni bir tugma bilan tinglash);
   - **qizil bayroqlar**: tashxis/davolash maslahati, bosim, asossiz va'da, shikoyat;
   - natija va sabab taklifi, qiziqish, qulay vaqt, keyingi qadam, 2–3 gaplik xulosa;
   - bemor savollari va e'tirozlari (haftalik dayjest uchun).
3. **Operatorga**: vazifa kartasida “AI xulosasi” chiqadi — **Tasdiqlash** (bir tugma) yoki
   **Tuzatish**. Operator o'zgartirgan joylar saqlanadi — promptni yaxshilash uchun eval to'plami.
4. **Rahbarga**: “Sifat nazorati” sahifasi — operatorlar va mezonlar bo'yicha ko'rsatkichlar,
   eng yomon/yaxshi qo'ng'iroqlar, qizil bayroqlar (ko'rib chiqildi deb belgilash), mezonlarni
   tahrirlash, har dushanba 08:00 da haftalik dayjest.
5. **Qo'ng'iroqdan oldin**: vazifada “Bemor haqida qisqacha” — tashriflar, oldingi suhbatlar
   xulosasi, ochiq vazifalar (6 soat keshlanadi).
6. **Tashxislar**: qoidaga tushmagan yozuvlarga AI toifa taklif qiladi (“AI taklifi” tugmasi yoki
   `python -m app.cli ai-diagnoses`); shifokor tasdiqlamaguncha bemorlarga qo'llanmaydi.

AI hech qachon o'zi vazifani yopmaydi, bemorga yozmaydi va qo'ng'iroq qilmaydi.

## Yoqish

`.env` ga:

```bash
OPENAI_API_KEY=sk-...
```

keyin:

```bash
docker compose -p radeski-crm -f docker-compose.prod.yml up -d --no-deps api worker worker-ai beat
```

Kalit qo'shilgach oxirgi 7 kunlik yozuvlar ham navbat bilan tahlil qilinadi (har 30 daqiqada
50 tadan). Holat va bugungi xarajat “Sifat nazorati” sahifasida va bosh sahifadagi “Tizim holati”da
ko'rinadi.

| O'zgaruvchi | Standart | Izoh |
|---|---|---|
| `AI_STT_MODEL` | `gpt-4o-mini-transcribe` | eng arzon ($0.003/daq); sifat yetmasa benchmark bo'yicha `gpt-transcribe` yoki `gpt-4o-transcribe` |
| `AI_LLM_MODEL` | `gpt-5.6-luna` | tahlil, xulosa, dayjest (arzon kichik model) |
| `AI_REASONING_EFFORT` | `low` | reasoning bo'lmagan model uchun bo'sh qoldiring |
| `AI_SERVICE_TIER` | `flex` | yarim narx, javob sekinroq; flex band bo'lsa so'rov bir marta oddiy tarifda takrorlanadi |
| `AI_MIN_TALK_SECONDS` | `20` | bundan qisqa suhbatlar tahlil qilinmaydi |
| `AI_MAX_OUTPUT_TOKENS` | `3000` | javob kesilsa oshiring |
| `AI_DAILY_BUDGET_USD` | `1.0` | kunlik chegara; tugasa yangi so'rovlar yuborilmaydi, tahlillar ertaga davom etadi (`0` = cheksiz) |

## Modelni tanlash (4.1 — STT benchmark)

1. 30 ta turli qo'ng'iroq yozuvini (o'zbekcha, ruscha, aralash, shovqinli) oling:
   `radeski_crm_recordings` volume'idan yoki “Qo'ng'iroqlar” sahifasidan yuklab.
2. Har biri uchun qo'lda to'g'ri matn yozing: `call01.mp3` + `call01.txt` (bir papkada,
   **git'dan tashqarida** — bu shaxsiy ma'lumot).
3. Serverda:

```bash
docker compose -p radeski-crm -f docker-compose.prod.yml run --rm -v /home/radeski-crm/data/stt:/stt api \
  python -m app.cli stt-benchmark --dir /stt
```

Natija: har model uchun WER (so'z xatosi foizi), vaqt va narx. Eng yaxshisini
`AI_STT_MODEL` ga yozing. WER 25% dan yuqori bo'lsa — o'zbek tiliga ixtisoslashgan STT provayderini
adapter orqali ulash kerak bo'ladi (`backend/app/integrations/stt/`).

## Ma'lumotlar himoyasi

- OpenAI'ga **audio** (STT uchun) va **transkript** (tahlil uchun) yuboriladi. Transkriptdagi
  telefon, pasport va karta raqamlari `[raqam]` bilan almashtiriladi. Bemor ismi, raqami va
  manzili qisqa ma'lumot uchun yuborilmaydi (faqat tashxislar, tashriflar va holatlar).
- IVR boshida “suhbat yozib olinadi va sifat nazorati uchun tahlil qilinadi” ogohlantirishi bo'lishi
  shart (`telephony/sounds/welcome.wav`).
- OpenAI tashkilot sozlamalarida (platform.openai.com → Settings → Data controls) ma'lumotni
  o'qitishda ishlatmaslik va minimal saqlash muddatini tanlang.
- Yakuniy sxemani yurist tasdiqlaydi (TZ 5-bo'lim).

## Narx va tejash

Sozlamalar eng arzon variantga qo'yilgan:

| Qayerda | Nima qilinadi |
|---|---|
| STT | jimlik kesiladi (har kanalda odam faqat o'z navbatida gapiradi → to'lanadigan daqiqa ~2 barobar kam), eng arzon model |
| Tahlil | promptga 14 ta skriptning hammasi emas, faqat shu qo'ng'iroqqa tegishli 2–3 tasi kiradi; `flex` tarif (yarim narx); bajarilgan mezonga izoh yozilmaydi |
| Takror | bitta qo'ng'iroq ikki marta tahlil qilinmaydi (qulf); transkript saqlanadi, qayta urinishda faqat tahlil qayta yuboriladi; 20 soniyadan qisqa suhbatlar o'tkazib yuboriladi |
| Qo'lda | bemor haqida qisqacha va chat javob loyihasi faqat tugma bosilganda; qisqacha 6 soat keshlanadi |
| Chegara | `AI_DAILY_BUDGET_USD` (standart $1/kun): tugasa yangi so'rov ketmaydi, tahlil ertaga davom etadi |

Jonli sinov (sintetik 45 soniyalik suhbat): transkripsiya $0.0018 + tahlil $0.0005 = **$0.0023**,
ya'ni suhbatning har daqiqasi ~$0.003. 2 operator × kuniga ~60 suhbat × 3 daqiqa ≈ oyiga
4 000 daqiqa → **taxminan $12–15/oy** (avvalgi sozlamalarda ~$70).
Aniq sarfni `platform.openai.com/usage` va bosh sahifadagi “bugun: $…” da kuzating.

## Keyingi qadam: real vaqtdagi maslahatchi (6-bosqich)

Hozir qo'ng'iroq oynasida operator skript va e'tirozlarga javoblarni o'zi tanlaydi. Avtomatik
maslahat uchun reja:

1. Asterisk: `AudioSocket()` (yoki ARI `externalMedia`) bilan suhbat ovozini (ikkala tomon alohida)
   ichki `live` xizmatiga oqim qilish — faqat operator ulanganidan keyin.
2. `live` xizmati ovozni OpenAI Realtime transkripsiya sessiyasiga uzatadi va tayyor bo'lakni
   (turn) Redis kanaliga yozadi.
3. Har yangi bemor gapidan keyin qisqa LLM so'rovi: e'tiroz turi → mos skript bo'lagi, kerak bo'lsa
   bo'sh vaqtlar (slot finder) — natija operator brauzeriga SSE orqali chiqadi.
4. Narx: ovoz daqiqasi ikki barobar (real vaqt + yakuniy tahlil); shuning uchun avval 4.1 benchmark
   va bir haftalik sinov, keyin yoqish/o'chirish sozlamasi bilan.

Shartlar: STT sifati o'zbek tilida benchmarkda yetarli bo'lishi (WER < 20%) va kechikish < 2 soniya.
